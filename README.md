# Customer Churn & Retention Analytics in D2C Beauty & Wellness

## Project Overview
This repository contains the analytical framework, feature definitions, and problem formulation to forecast customer churn and understand repeat purchase drivers for a Direct-to-Consumer (D2C) skincare brand.

- **Track:** Data Science with Python Analyst
- **Organization:** Yuva Internship
- **Author:** Adnan Shah Ashfaque Shah
- **Location:** Coimbatore

## Business Problem Summary
- The brand faces a 55% to 60% customer churn within 90 days of the first purchase.
- The objective is an early-warning predictive system targeting at-risk users within 30-45 days to reduce churn by 10-15%.

## Planned Methodology
1. **Data Ingestion & Cleaning:** Missing value handling, session data auditing via pandas.
2. **Exploratory Data Analysis:** Cohort analysis, category retention curves, discount impact.
3. **Feature Engineering:** RFM scoring, basket size, and review sentiment metrics.
4. **Modeling:** Logistic Regression baseline, Random Forest, and XGBoost classifiers.
